Mandarin g2pM reading pack
===========================

This directory is the shared offline Mandarin reading pack used by the eza式
reader and the Standard Pinyin plain projection. Nothing is downloaded at run
time. The manifest records source pins, file SHA-256 receipts, model tensor
layouts, and attribution. The same directory is loadable by the pinned
TypeScript engine and by the Android Java reader.

Integrity
---------

manifest.json records the SHA-256 and byte length of every pack member. The
runtime verifies every member before constructing the reader. A missing or
modified file makes Mandarin readings unavailable; there is no fallback
dictionary.
